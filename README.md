# HTML_Website_ForStudentsinfo_3CS

Welcome to the **HTML_Website_ForStudentsinfo_3CS** project! This repository contains a foundational HTML website developed for students, designed to manage and display student information effectively.

## 📌 Overview

This project serves as an educational demonstration of basic web development principles. It is structured into two main versions to illustrate the impact of styling:
- **`Avec_Css`**: The styled version of the website, incorporating CSS to enhance the user interface and user experience.
- **`Sans_CSS`**: The bare-bones HTML structure, demonstrating the semantic layout and content organization without any visual styling.

## 🚀 Features

- **Student Information Access**: Retrieve and view details about students in just a few clicks.
- **Comparative Design**: Directly compare the raw HTML layout with its CSS-styled counterpart to understand the role of Cascading Style Sheets in web design.
- **Simple & Accessible**: A lightweight, straightforward implementation ideal for beginners in web development.

## 📁 Repository Structure

- `Avec_Css/`: Contains the styled HTML pages and associated CSS files.
- `Sans_CSS/`: Contains the raw, unstyled HTML pages.
